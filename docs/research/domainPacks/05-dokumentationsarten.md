# Dokumentationsarten

## Diátaxis

Diátaxis unterscheidet vier grundlegende Arten technischer Dokumentation:

- Tutorial
- How-to
- Reference
- Explanation

Jeder Typ hat einen anderen Zweck und sollte entsprechend anders geschrieben werden.
